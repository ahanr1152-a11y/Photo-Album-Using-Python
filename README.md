# Photo-Album-Using-Python
Python Photo Album – Image Slideshow

A simple Photo Album & Slideshow application built with Python using Tkinter for the graphical user interface and Pillow (PIL) for image processing.

✨ Features

- 🖼️ Displays multiple images in a single application window
- ▶️ Plays images automatically as a slideshow
- ⏱️ Automatically changes images every 2 seconds
- 🔘 Simple "Play the Slideshow" button
- 📐 Resizes images for consistent display
- 🎨 Clean and beginner-friendly GUI
- 📂 Supports images stored on the local system

🛠️ Technologies Used

- Python
- Tkinter – GUI development
- Pillow (PIL) – Image loading, resizing and display
- Time module – Slideshow timing

📚 What I Learned

Through this project, I practiced:

- Creating GUI applications with Tkinter
- Working with external Python libraries
- Handling and displaying images using Pillow
- Using lists and loops to manage multiple images
- Creating buttons and connecting them to functions
- Understanding event-driven programming
- Building a complete Python mini-project from scratch

🚀 How to Run

1. Install Python.
2. Install Pillow:

pip install pillow

3. Add your image paths to the "image_paths" list.
4. Run the Python file:

python PhotoAlbum.py

The goal of this project was to strengthen my Python fundamentals, GUI development, image processing, and practical project-building skills by creating a functional desktop application.
